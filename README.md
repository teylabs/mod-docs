# Mod Documentation

Source for the documentation site of [tey/mod](https://github.com/teylabs/mod), published at [mod.teylabs.com](https://mod.teylabs.com).

The site is built with [VitePress](https://vitepress.dev). Pages live in `docs/`, and every push to `main` deploys the site through GitHub Pages.

```bash
npm ci
npm run dev     # http://localhost:5173
npm run build   # checks the footer credit line, then builds .vitepress/dist
```

The brand kit (mark, favicons, banner and share card) is generated by `brand/build.mjs`; see [brand/README.md](brand/README.md).
